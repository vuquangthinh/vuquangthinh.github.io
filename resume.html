AmbuSun | RCM Services

AmbuSun is a healthcare revenue cycle management platform focused on helping providers streamline claims, denials, payer follow-up, reimbursement workflows and revenue visibility. It brings together operational reporting, claim management and AI-assisted support for billing teams.

Overview

AmbuSun helps healthcare organizations improve financial performance by reducing claim delays, managing denial lifecycles and accelerating reimbursement cycles. The platform supports end-to-end revenue operations from patient access and billing through collections and payer follow-up.

My role

I worked as a Full-stack developer building and evolving the reporting, denial management and AI Chat modules. My responsibilities included product workflows, backend APIs, data models, dashboard logic, UI implementation, and operational features used by revenue cycle teams.

What I built

  • Denial management workflows for tracking, prioritizing and resolving claim denials.
  • Reporting modules for KPI dashboards, aging buckets, payer performance and operational visibility.
  • AI Chat features to help users quickly search claim data, summarize denial cases and support agent workflows.
  • Admin and operational tools for status tracking, case ownership, escalation and audit trails.
  • Data integrations and analytics layers to support decision-making across claims, payment and collections.

Mô tả ngắn gọn

AmbuSun là nền tảng quản lý doanh thu y tế (RCM) giúp các cơ sở chăm sóc sức khỏe tối ưu hóa quy trình claim, denial, theo dõi nhà cung cấp thanh toán và tăng hiệu quả thu hồi doanh thu. Nền tảng kết hợp báo cáo vận hành, quản lý denial và AI Chat để hỗ trợ đội ngũ billing, revenue cycle và support.

Tôi làm Full-stack developer, xây dựng và phát triển các module reporting và quản lý denial, đồng thời tích hợp AI Chat hỗ trợ xử lý câu hỏi, tóm tắt hồ sơ denial và hỗ trợ nhân viên vận hành làm việc hiệu quả hơn.

Node.js (backend, JavaScript runtime) · React.js (web UI library) · PostgreSQL (SQL database) · Reporting · Denial Management · AI Chat · RCM
Close Fintech / analytics

Quantizero

Quantizero is a financial analytics and trading-signal platform built to translate market data into actionable alpha signals for backtesting, monitoring and operational decision support.

Overview

The platform brings together market data ingestion, signal generation, dashboard reporting and service orchestration for a fast-moving fintech workflow. It was designed to support both analytics and daily trading operations while keeping the infrastructure lean and maintainable.

My role

I worked across backend engineering, service design and frontend dashboard development. My work included building the API layer with Python and Python (FastAPI framework), designing data flows for analytics jobs, and implementing React-based views for operational monitoring and signal review.

What I built

  • Python (FastAPI framework) services for data collection, signal processing and reporting endpoints.
  • Dashboard UI for charting, summary KPIs, signal status and trading insights.
  • Deployment setup on k3s with containerized service orchestration and environment isolation.
  • Operational monitoring logic to keep analytics jobs and service health visible to the team.
  • Data model and API contracts to support future expansion into more market feeds and strategy modules.

Why it mattered

The project required balancing speed with reliability: signals had to be generated quickly enough to be useful, while the system also needed to stay transparent and manageable in production. The architecture focused on clean service boundaries, API consistency and straightforward monitoring so the product could evolve without constant rework.

Node.js (backend, TypeScript) · Python · Python (FastAPI framework) · React.js (web UI library) · TypeScript · k3s · Financial Analytics · Trading Signals
